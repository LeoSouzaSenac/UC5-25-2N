---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#f97316;">What is Future?</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 O <strong>Future</strong> é usado para falar sobre ações que vão acontecer, planos, decisões e previsões.
</p>

| USE                                             | EXAMPLE                                                           |
| ----------------------------------------------- | ----------------------------------------------------------------- |
| <span style="color:#e2e8f0;">Ação futura</span> | <span style="color:#e2e8f0;">I will study tomorrow.</span>        |
| <span style="color:#e2e8f0;">Plano</span>       | <span style="color:#e2e8f0;">She is going to work tonight.</span> |
| <span style="color:#e2e8f0;">Previsão</span>    | <span style="color:#e2e8f0;">We will deploy the system.</span>    |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#22c55e;">Main Rule</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 No Future, o verbo principal permanece na <strong>forma base</strong>.
</p>

| BASE VERB                                 | FUTURE                                             |
| ----------------------------------------- | -------------------------------------------------- |
| <span style="color:#e2e8f0;">work</span>  | <span style="color:#e2e8f0;">will work</span>      |
| <span style="color:#e2e8f0;">study</span> | <span style="color:#e2e8f0;">going to study</span> |
| <span style="color:#e2e8f0;">fix</span>   | <span style="color:#e2e8f0;">will fix</span>       |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#e879f9;">Future with WILL</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 Usamos <strong>will</strong> para decisões rápidas, promessas e previsões.
</p>

| STRUCTURE                                                       | EXAMPLE                                              |
| --------------------------------------------------------------- | ---------------------------------------------------- |
| <span style="color:#e2e8f0;">Subject + will + base verb</span>  | <span style="color:#e2e8f0;">I will work.</span>     |
| <span style="color:#e2e8f0;">Subject + won't + base verb</span> | <span style="color:#e2e8f0;">She won't study.</span> |
| <span style="color:#e2e8f0;">Will + subject + base verb?</span> | <span style="color:#e2e8f0;">Will you work?</span>   |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#38bdf8;">Future with GOING TO</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 Usamos <strong>going to</strong> para planos e intenções já definidas.
</p>

| STRUCTURE                                                                        | EXAMPLE                                                       |
| -------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| <span style="color:#e2e8f0;">Subject + am/is/are + going to + base verb</span>   | <span style="color:#e2e8f0;">I am going to study.</span>      |
| <span style="color:#e2e8f0;">Subject + to be + not + going to + base verb</span> | <span style="color:#e2e8f0;">She isn't going to work.</span>  |
| <span style="color:#e2e8f0;">To be + subject + going to + base verb?</span>      | <span style="color:#e2e8f0;">Are they going to deploy?</span> |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#ef4444;">Difference: WILL vs GOING TO</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 "Will" normalmente indica decisão rápida.  
"Going to" normalmente indica plano já definido.
</p>

| WILL                                                   | GOING TO                                                    |
| ------------------------------------------------------ | ----------------------------------------------------------- |
| <span style="color:#e2e8f0;">I will help you.</span>   | <span style="color:#e2e8f0;">I am going to help you.</span> |
| <span style="color:#e2e8f0;">Decisão no momento</span> | <span style="color:#e2e8f0;">Plano anterior</span>          |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#facc15;">Common Time Expressions</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 Palavras comuns usadas com Future.
</p>

| EXPRESSION                                    | TRANSLATION                                        |
| --------------------------------------------- | -------------------------------------------------- |
| <span style="color:#e2e8f0;">Tomorrow</span>  | <span style="color:#e2e8f0;">Amanhã</span>         |
| <span style="color:#e2e8f0;">Next week</span> | <span style="color:#e2e8f0;">Semana que vem</span> |
| <span style="color:#e2e8f0;">Later</span>     | <span style="color:#e2e8f0;">Depois</span>         |
| <span style="color:#e2e8f0;">Soon</span>      | <span style="color:#e2e8f0;">Em breve</span>       |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#14b8a6;">Common Mistakes</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px; line-height:2;">
❌ I will worked → ✔ I will work <br>
❌ I will working → ✔ I will work <br>
❌ I am going work → ✔ I am going to work <br>
❌ She is going to studying → ✔ She is going to study
</p>

</div>

📝 Future Practice
</h1>

</p>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#f97316;">work</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 Regra: Com <strong>will</strong>, o verbo permanece na forma base.  
<strong>work → will work</strong>
</p>

| SIMPLE PRESENT                              | FUTURE                                           | NEGATIVE                                          | QUESTION                                         |
| ------------------------------------------- | ------------------------------------------------ | ------------------------------------------------- | ------------------------------------------------ |
| <span style="color:#e2e8f0;">I work.</span> | <span style="color:#e2e8f0;">I will work.</span> | <span style="color:#e2e8f0;">I won't work.</span> | <span style="color:#e2e8f0;">Will I work?</span> |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#22c55e;">study</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 O verbo principal continua na forma base após <strong>going to</strong>.  
<strong>study → going to study</strong>
</p>

| SIMPLE PRESENT                                   | FUTURE                                                     | NEGATIVE                                                      | QUESTION                                                   |
| ------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| <span style="color:#e2e8f0;">She studies.</span> | <span style="color:#e2e8f0;">She is going to study.</span> | <span style="color:#e2e8f0;">She isn't going to study.</span> | <span style="color:#e2e8f0;">Is she going to study?</span> |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#e879f9;">deploy</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 Após <strong>will</strong>, o verbo nunca muda.
<strong>deploy → will deploy</strong>
</p>

| SIMPLE PRESENT                                         | FUTURE                                                      | NEGATIVE                                                     | QUESTION                                                    |
| ------------------------------------------------------ | ----------------------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------- |
| <span style="color:#e2e8f0;">We deploy systems.</span> | <span style="color:#e2e8f0;">We will deploy systems.</span> | <span style="color:#e2e8f0;">We won't deploy systems.</span> | <span style="color:#e2e8f0;">Will we deploy systems?</span> |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#38bdf8;">fix</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 O verbo principal fica na forma base depois de <strong>going to</strong>.  
<strong>fix → going to fix</strong>
</p>

| SIMPLE PRESENT                                     | FUTURE                                                       | NEGATIVE                                                        | QUESTION                                                     |
| -------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------- | ------------------------------------------------------------ |
| <span style="color:#e2e8f0;">He fixes bugs.</span> | <span style="color:#e2e8f0;">He is going to fix bugs.</span> | <span style="color:#e2e8f0;">He isn't going to fix bugs.</span> | <span style="color:#e2e8f0;">Is he going to fix bugs?</span> |

</div>

---

<div style="background:#1e293b; padding:25px; border-radius:20px; margin-top:30px;">

<h1 style="color:#ef4444;">build</h1>

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 O futuro pode usar <strong>will</strong> ou <strong>going to</strong>.  
<strong>build → will build / going to build</strong>
</p>

| SIMPLE PRESENT                                               | FUTURE                                                            | NEGATIVE                                                           | QUESTION                                                          |
| ------------------------------------------------------------ | ----------------------------------------------------------------- | ------------------------------------------------------------------ | ----------------------------------------------------------------- |
| <span style="color:#e2e8f0;">They build applications.</span> | <span style="color:#e2e8f0;">They will build applications.</span> | <span style="color:#e2e8f0;">They won't build applications.</span> | <span style="color:#e2e8f0;">Will they build applications?</span> |

</div>

📝 Exercises

<p style="color:#cbd5e1; background:#334155; padding:15px; border-radius:12px;">
📘 Agora pratique o <strong>Future</strong> usando <strong>will</strong> e <strong>going to</strong>.

<h2 style="color:#f97316;">A) Complete com o verbo correto</h2>

<div style="color:#e2e8f0; line-height:2;">
1. I will ______ (work) tomorrow <br>
2. She will ______ (study) later <br>
3. They are going to ______ (deploy) <br>
4. We will ______ (fix) the bug
</div>

---

<h2 style="color:#22c55e;">B) Use "will" ou "going to"</h2>

<div style="color:#e2e8f0; line-height:2;">
1. I ______ help you (decisão agora) <br>
2. I ______ study tonight (planejado) <br>
3. We ______ fix the problem (decisão rápida)
</div>
